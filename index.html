B4 Signal API v1

Five members. One clear contract.

Add these members to any NinjaTrader 8 indicator and its signals can be read by B4 tools and by any other NinjaScript, exactly like built-in indicator series. The API publishes signals only; it never places orders.

MemberTypeMeaning
B4UseEntrySignalsbool settingTurns entry signals on or off (default on)
B4UseConfirmationsbool settingTurns the confirmation series on or off (default on)
B4BuySignalsSeries<bool>true only on the bar that produced a buy signal
B4SellSignalsSeries<bool>true only on the bar that produced a sell signal
B4ConfirmationDirectionsSeries<int>1 long bias, -1 short bias, 0 none, for the current bar

Pulse, then reset

Reset every bar to false / false / 0, then publish. A signal is true only on the bar it happened.

Exact names, exact attributes

Tools match by name. Keep the types, the settings group "B4 CoPilot Pro Integration" and the empty setters.

Signals, never orders

API indicators publish information only. Execution stays with a strategy or tool the trader controls.

Install

Up and running in minutes.

Demo indicators (NinjaTrader 8)

  1. Make sure you are flat, ideally with the market closed.
  2. Copy the .cs file into Documents\NinjaTrader 8\bin\Custom\Indicators\.
  3. Open the NinjaScript Editor and compile (F5); check for errors.
  4. Add "B4 API Demo - ..." to a chart. The B4 settings sit under B4 CoPilot Pro Integration.

Skill library (Claude Code)

  1. Unzip the library.
  2. Copy a skill folder into %USERPROFILE%\.claude\skills\ for personal use, or .claude\skills\ inside a project.
  3. Ask for NinjaTrader 8 work as usual; the matching skill loads automatically from its description.

The demos place no orders, read no account data and write no files. They are learning material, not trading systems. Community projects built with this kit are third-party work unless B4 reviews and supports them.
