Intellectual property protection

AI that extends B4 without exposing it.

B4 Indicator AI is built on public interfaces only. Protection does not rely on telling an AI to keep a secret: protected information is never made available to it in the first place.

Never accessible

  • B4 Algo source code, calculations, formulas and algorithms
  • B4 confirmation criteria, gates, weights and decision logic
  • Internal signal-generation rules and implementation details
  • Private DLL internals and protected development source
  • Internal research records, training labels and confidential documentation
  • Reconstruction of any of the above through repeated queries or collected outputs

What AI can work with

  • The public B4 Signal API contract and the official repository
  • Your own indicators and your own NinjaScript code
  • Public NinjaTrader 8 documentation and APIs
  • General technical-analysis concepts and education
  • Data you explicitly authorize, and only outputs B4 approves for customer use

Deny by default. Every AI tool, data field and integration endpoint must be on the B4 Public Interface Allowlist before it is reachable. Unknown or new fields stay blocked until reviewed. The boundary is enforced on B4's side, every request is checked, bulk extraction is limited, and any confirmed leak blocks a release.

B4 Indicator MCP · in development

A safe way for AI clients to use B4 Indicators.

The Model Context Protocol lets compatible AI clients discover and use approved tools. The public B4 Indicator MCP server is in development and is not available yet. It will cover public material only.

GroupPlanned scope (public material only)Status
DiscoverList the official repositories, read the B4 Signal API contract and documentation, version and compatibility info.Planned
ExplainExplain technical-analysis concepts and your own indicators; troubleshooting with the error database.Planned
ConfigureValidate and preview settings for your own indicators; never silently overwrite saved workspaces.Planned
ResearchHistorical analysis of your own indicator logic on data you authorize, with validation reports.Planned
InspectOnly outputs B4 explicitly approves for customer use. No B4 Algo internals or confirmation states.Under review

MCP access never grants trading authority. Research and simulation stay separate from live execution, and nothing places orders on its own.
